# Запуск Armina Hair через @ArminaHair_Bot

Подготовленная версия предназначена для демонстрации. Мастера, цены и услуги примерные.

1. Загрузить содержимое проекта в корень `lordiklolkek/Armina-hair-tma`, сохранив папки. В корне должны находиться `main.py`, `requirements.txt` и `render.yaml`; архив ZIP на хостинге не распаковывается автоматически.
2. В Render выбрать **New → Blueprint**, подключить репозиторий и применить `render.yaml`. Конфигурация явно выбирает **Free**.
3. В защищённой форме Render ввести токен существующего **@ArminaHair_Bot** и числовой `ADMIN_CHAT_ID`. Токен вводится только на хостинге, не в GitHub и не в переписке.
4. Если ID неизвестен, сначала создать Web Service вручную с `BOT_TOKEN`, `BOT_USERNAME=ArminaHair_Bot`, `WEBHOOK_SECRET` и остальными параметрами из `.env.example`, оставив `ADMIN_CHAT_ID` пустым. После запуска отправить боту `/id`, записать выданное число в настройки Render и передеплоить. До настройки администратора запись заблокирована.
5. Дождаться работающего сервиса: его `/health` должен возвращать `{"ok":true}`. Адрес Render сервер подставляет автоматически.
6. В личном чате с **@ArminaHair_Bot** нажать `/start`, затем **«Открыть запись»** или кнопку меню **«Записаться»**. Проверить создание заявки и сообщения клиенту и администратору.
7. Администратор отправляет `/admin` и открывает панель. Проверить подтверждение, отмену и освобождение отменённого времени.
8. Для кнопки запуска в профиле бота: **@BotFather → Bot Settings → Configure Mini App → Main Mini App**, указать HTTPS-адрес сервиса. Прямая ссылка `https://t.me/ArminaHair_Bot?startapp` работает после этой настройки.

| Параметр | Где задаётся |
| --- | --- |
| `BOT_TOKEN` | Защищённые настройки Render; секрет существующего бота |
| `ADMIN_CHAT_ID` | Защищённые настройки Render; числовой ID владельца или группы |
| `BOT_USERNAME` | Уже указан в `render.yaml`: `ArminaHair_Bot` |
| `WEBHOOK_SECRET_SEED` | Render генерирует автоматически; приложение преобразует в секрет вебхука |
| `PUBLIC_BASE_URL` | Не требуется на Render; используется автоматический `RENDER_EXTERNAL_URL` |
| `SALON_NAME`, `SALON_ADDRESS` | Демо-значения в `render.yaml`; заменить при подготовке реального салона |

Render Free не сохраняет локальную SQLite-базу между перезапусками и деплоями. Для демонстрации это допустимо; для работы с реальными клиентами нужен постоянный диск и резервные копии.

Источники: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Render Blueprint](https://render.com/docs/blueprint-spec), [переменные Render](https://render.com/docs/environment-variables).
