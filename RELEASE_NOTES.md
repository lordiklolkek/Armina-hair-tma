# Armina Hair — GitHub-ready source

Демонстрационный Telegram Mini App: FastAPI, SQLite, Telegram WebApp SDK, клиентская запись и админ-панель. Данные мастеров и цен примерные.

Это **исходный код**, не опубликованный сервис. Перед обслуживанием реальных клиентов нужны HTTPS, подключение бота, постоянная БД с резервным копированием и полноценные интеграционные тесты.

## Обновление 11 октября 2026

- Исправлена установка SQLAlchemy для asyncio: теперь явно устанавливается обязательный greenlet.
- Исправлено возможное раскрытие токена в HTTP-журналах и текстах сетевых ошибок Telegram.
- Добавлен единый атомарный API сохранения графика и выходных; админ-панель использует его.
- Выбор времени блокируется во время обновления слотов; недоступное время сбрасывается.
- Услуга без действующего мастера недоступна для выбора.
- Добавлены Render Blueprint, Python 3.12, автоматическое определение HTTPS-адреса Render и совместимый секрет вебхука.
- Перед настройкой бота проверяется принадлежность токена @ArminaHair_Bot; добавлены команды start, admin, id.
- Успешно выполнены 18 серверных и 3 клиентских теста. Живая доставка Telegram и внешний хостинг ещё не проверены.
