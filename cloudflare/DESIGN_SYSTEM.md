# 37 · тёмный интерфейс с бирюзовым акцентом

Визуальное направление согласовано пользователем 23.10.2026 по двум предоставленным скриншотам VPNUS VPN. Ранние синие изображения — только отброшенные концепции, не текущий дизайн. Реализован существующий Cloudflare frontend; исходный Render frontend намеренно не переписан (он сохранён для возврата).

## Общие правила

- Основной фон #0D1010, карточки #151A1A, акцент #08C9BE, дополнительный #0A817C; основной текст #F5F7F7. Второстепенный текст #A1AFAF немного светлее исходного ориентира для чтения мелких подписей.
- Токены в public/style.css, формы/карточки общие для всех ролей. Основные скругления 28–32 px, поля/второстепенные кнопки 16–22 px. Кнопки от 44 px, основные от 52 px.
- Статичные радиальные градиенты, лёгкие внутренние блики. Blur 12 px применяется только к одной навигационной панели и имеет непрозрачный fallback. Нет анимированных градиентов/тяжёлых фильтров.
- Плавающая нижняя панель сохраняет все разрешённые сервером разделы, текстовые подписи и доступную активную вкладку; у администратора-мастера четыре пункта. Роли по-прежнему определяет сервер.
- Safe areas учитывают CSS env и Telegram safeAreaInset/contentSafeAreaInset, с обновлением по событиям. Цвета приложения не наследуют светлые системные поверхности Telegram. Клавиатура скрывает нижнюю панель при уменьшении видимой области; требуется проверка на настоящих iPhone/Android.
- Микроанимации 180–200 ms, prefers-reduced-motion отключает их. Видимый фокус, aria-current для навигации/шагов, aria-pressed для выбранных дат/слотов, aria-busy во время действий.
- Модальное подтверждение отмены и возврата недельного графика: native dialog, фокус на безопасном действии, Escape отменяет, фокус возвращается. Для старых WebView есть прежнее системное подтверждение.

## Экраны

Клиент: компактная шапка с CTA, услуги с отдельным ценником и длительностью, реальные фото профилей мастеров при наличии (lazy loading, fallback на инициал), семь быстрых дат плюс системный выбор произвольной даты, слоты, проверка визита, подтверждение контакта, успех, мои записи/перенос/отмена, ближайший активный визит на первом шаге.

Мастер/администратор: общая система карточек и форм, выделение выбранного подраздела, календарь с фильтрами, недельный график/исключения/отсутствие, услуги и длительности, клиенты и заметки, приглашения и архив, настройки, диагностика/экспорт, QR. Цены/длительности/доступность берутся из прежних API, схема D1 и backend не менялись.

Языки интерфейса HY/RU сохранены. Дни и месяцы HY выводятся из явного армянского словаря: Intl в части браузеров иначе использует русский fallback. Системный календарь/часы самого телефона может показывать язык ОС. Требование об армянском языке сообщений и кнопки бота нужно учитывать отдельным изменением Telegram; этот UI-этап исходники backend не меняет.

## Воспроизводимая визуальная проверка

Только локально: tests/wrangler.ui.jsonc, отдельная .wrangler/ui-proof, фиктивный ID 1/тестовый токен. Путь /__preview доступен исключительно через tests/ui-fixture.ts на localhost; основная сборка его не импортирует. Контролы меняют настоящий iframe viewport, тему тестового Telegram и safe areas. Отчёт показывает clientWidth и горизонтальное переполнение, не читает приватные данные. Из-за рамки/полосы прокрутки фактические ширины немного меньше подписанных.

Проверки фиксируются в PROJECT_PROGRESS.md; локальный браузерный тест не равен проверке настоящего Telegram. Реальные фотографии мастеров пока не предоставлены: случайные лица/стоковые сотрудники не добавлялись.

Документация SDK: https://core.telegram.org/bots/webapps (safe areas, BackButton, цвета баров, viewport).
