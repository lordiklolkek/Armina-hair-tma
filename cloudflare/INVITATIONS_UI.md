# Telegram-приглашения мастеров

Доступ: Управление → мастер → Изменить. Обновление 27 октября 2026, Worker 4743870f-92c9-40dd-873c-7274c1df5493.

## Для администратора

Если Telegram не привязан, нажмите «Создать ссылку». Передавайте её только нужному мастеру: тот, кто первым примет действующее приглашение, получит доступ к этому профилю.

- «Скопировать ссылку» вызывает Clipboard API непосредственно из нажатия. Если он недоступен/отказал, применяется резервное копирование выделенного текста; при отказе показана инструкция ручного копирования. «Выделить ссылку» даёт отдельное явное действие для iPhone, Android и компьютеров.
- «Отправить барберу» открывает стандартный выбор чата Telegram через https://t.me/share/url; в Mini App — openTelegramLink. Отправку завершает сам администратор. Система не определяет адресата автоматически, не отправляет сообщения от бота и не считает открытие выбора чата фактом доставки.
- «Создать новую ссылку» заменяет предыдущую тем же серверным API. Срок остаётся 900 секунд, токен одноразовый. Таймер считается от начала запроса; проверяются wall/monotonic clocks, в том числе при возврате из фона. Решение о действительности всегда остаётся за сервером.
- По истечении срока текст ссылки очищается, действия старого приглашения отключаются. При потере ответа создания старая ссылка также не используется: сервер мог уже заменить токен.
- «Обновить статус» перечитывает профиль с сервера. При возвращении в окно обновление выполняется автоматически с ограничением частоты. После успешной привязки ссылка скрывается и показан статус «Telegram привязан». Неиспользованные ссылки не восстанавливаются после перезагрузки/ухода; создайте новую.
- Уже привязанный аккаунт не заменяется приглашением. Отзыв доступа требует подтверждения и существующего контроля версии, история визитов сохраняется.

## Реализация и проверки

Новый публичный модуль invitations.js, подключение в app.js, единые стили и переводы HY/RU. Токены не сохраняются в localStorage, адресной строке или логах. Сервер, хеширование/проверка токенов, срок, права, схема и конфигурация не менялись. Рабочая D1 и webhook не изменялись; тестовые операции выполнялись в отдельной локальной базе.

Полный локальный набор 102/102, Python 19/19, общий JS 3/3; typecheck/синтаксис и GitHub CI успешны. Тесты покрывают ограничения буфера, ручное выделение, строгий адрес текущего бота, кодирование сообщения/ссылки, истечение и перевод часов, блокировку кнопок, замену/одноразовость, обновление привязки и сетевую ошибку создания. В браузере RU/HY проверены при фактической ширине 305/375px без горизонтального переполнения. Нативный Telegram на настоящем iPhone/Android требует подтверждения пользователя; запрос отправлен. Фиктивные ссылки локальной проверки не пригодны для рабочего подключения.

Справочные первоисточники: [Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API), [Telegram openTelegramLink](https://core.telegram.org/bots/webapps), [Telegram share links](https://core.telegram.org/widgets/share).
